## Troubleshooting

### "App not installed" Error

**Solution:**
- Uninstall any previous version
- Make sure you have enough storage space
- Enable "Install unknown apps" in settings

### "Parse error" or "File corrupted"

**Solution:**
- Re-download the APK
- Make sure download completed fully
- Try downloading on a different browser

### App Crashes on Startup

**Solution:**
- Clear app data: Settings → Apps → GreenHeal → Clear data
- Uninstall and reinstall
- Make sure your Android version is 8.0 or higher

### Notifications Don't Work

**Solution:**
- Go to Settings → Apps → GreenHeal → Notifications
- Enable all notification permissions
- Make sure "Do Not Disturb" is off
