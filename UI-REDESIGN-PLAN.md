# GreenHeal UI Redesign Plan

- **Primary**: Sage Green (#6B9080) - healing, growth, recovery
- **Secondary**: Soft Lavender (#9B8FA5) - calm, peace
- **Accent**: Warm Terracotta (#D4A574) - grounding, stability

- **Text**: Deep Teal (#2C3E3D)

## Design Principles
- **Healing-focused**: Calming colors, soft shadows, rounded corners
- **Accessible**: High contrast, large touch targets, clear labels
- **Modern**: Gradients, glassmorphism, smooth animations
- **Professional**: Consistent spacing, typography hierarchy

Focus on fixing bugs first, then UI enhancements in next iteration.
